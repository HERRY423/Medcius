# P0 数据、证据与静默采集契约

本说明对应 2026-10-04 的本地 P0 加固。适用对象是部署维护者和验证人员。工程检查、合成评测终点、医院验收和临床证据是不同状态。

## 正式只读来源的装配

启动入口 `scripts/serve.mjs` 在启动服务前调用来源装配器。部署方可设置 `MEDCIUS_HOSPITAL_SOURCE_MODULE`，值必须是本地绝对路径，模块导出 `createHospitalSourceBindings({ siteActivation })`。模块由部署维护者控制，HTTP 请求不能提供模块路径或连接凭据。

返回契约：

```javascript
export async function createHospitalSourceBindings({ siteActivation }) {
  return {
    siteActivation,
    dependencies: {
      channel: "view-library",
      queryView: async (view, params) => { /* 院内只读实现 */ },
    },
    authorizeContext: async (context, auth) => {
      // 必须核实该医生对该租户、患者、就诊的访问权限。
      // 无可核验的院内授权结果时返回 false。
      return false;
    },
    timeWindow: "24h",
    specialtyRulePackId: null,
  };
}
```

示例默认拒绝访问，不能当作医院授权实现。连接参数遵循 `site-connector-factory.mjs` 的实际接口；院端激活材料、只读凭据、PHI 盐和访问策略需要单独配置和验收。开启真实数据开关而未装配来源时拒绝启动。

正式采集从认证结果获取医生与租户，从服务端固定复核时点、时间窗和规则包。请求只提交患者/就诊标识，禁止替换上述字段及注入 `dataFeeds`。来源记录的患者或就诊不匹配时拒绝；缺失归属信息保留缺口，不以请求上下文冒充来源证明。

## 静默档案与重放

- 普通采集响应不含研究输入、完整来源数据或研究摘要副本。静默阶段不提供临床卡片、病程草稿或写回。
- 研究档案使用 v2 格式，按租户分目录，创建后不得覆盖。内容摘要覆盖上下文、输入、输出、来源、失败信息和算法身份。
- 归档前必须重放一致；算法身份记录本地静态模块依赖源码摘要及 Node 版本。不同算法身份拒绝声称相同重放。
- 研究读取/重放 API 需要相应角色、同一租户，以及完整审计链中的采集哈希锚点。孤立文件不能通过 API 导出。
- 旧档案不自动迁移或删除。仍需在实际部署核实操作系统权限、备份和恢复流程。此档案属于本地研究记录，不能代替医院审计平台或独立见证。

## PHI 与签收兼容性

结构化身份字段支持嵌套对象、FHIR 数组和数字标识符；HMAC 使用部署盐，缺盐时遮除身份值。自由文本仍采用规则检测，不能据此宣称任意文本都已完全去标识化。

新审计记录覆盖完整事件元数据和正文，签收另有完整链。新签名绑定 `event_digest`、租户、注册签署者、公钥、决定、理由和防重放标识；旧的 `payload_hash` 签名调用应拒绝。未签名的研究审阅记录明确标记 `signature_verified: false`。

系统生成的研究摘要哈希在审计正文中采用 32 字节数组，研究编号采用分组编码，避免十六进制数字片段被误认为电话号码；API 对外摘要与档案编号仍保持原格式。通用审计正文没有 PHI 扫描豁免。签收信封仅在与服务端重算结果完全一致后，才对两个可信摘要字段采用字节扫描视图，签名和存储字节保持原契约。

数据库迁移只新增字段，不重写旧行和旧哈希。旧事件/签收返回 `LEGACY_*_UNVERIFIABLE`，不能被自动提升为可信 v2 记录。读回及导出若发现旧记录中的原始 PHI 会拒绝出口。生产 CA/身份注册与独立外部链头检查点仍需另行实现和验收。

包含旧链的库不会满足研究 API 要求的完整 v2 链校验，因此升级后的研究导出可能被阻断。实际升级前需要单独的历史证据保留、人工复核与新链启用方案；本轮未自动迁移历史库。

## 证据与临床含义

- 引用检查只验证与给定证据文本的精确对应，不能验证来源真实性或临床蕴含。自由改写留待复核，不能只因引用 ID 存在就通过。
- 缺失、空字符串和布尔值不转为测量零值；无法比较的单位和参考区间不输出正常结论。未记录与明确零值分开。
- NEWS2 缺项返回未知，候选分数来自同一条测量记录；P0 摘要不自动触发响应流程。eGFR 计算保护不伪装成来源上报的 AKI 诊断或处置时限。
- 评测缺失标注、重复键、弃答、无类别变异和空队列必须进入分母或不可计算状态。调用方标志不能升级证据等级。
- 主检查的 `synthetic_execution_pass` 仅代表脚本完成；合成评测终点见各报告及 JSON 摘要。临床证据仍未确立。

## 验证入口

`node scripts/run-all-checks.mjs` 将五个 P0 专项套件纳入主流程，并为子进程创建临时审计数据目录。HTTP 套件只使用本地回环。该流程不授权连接医院或使用真实患者资料。

必须另行执行并报告 `AGENTS.md` 要求的外部插件校验器；校验器路径不存在时记为未完成，不能以主流程绿灯替代。
