# Medcius V1.0.0

Medcius 为宿主 Agent 提供受约束的临床工作流技能、只读数据工具、PHI 防护、
来源追溯和审计能力。本次为工程版本发布；版本号不代表医院部署验收或临床有效性已建立。

## 本版内容

- 中文病历断言、测量、CDA 身份、院内视图映射、医嘱执行和 PACS 来源链接。
- 会话词典与本地 CPU NER 双轨 PHI，覆盖 HIS、MCP、文档、审计和模型输入输出；
  模型缺失、推理失败或扫描不完整时继续阻断。
- 本地 NER 独立批处理、数值等价性、并发与故障回归。
- 离线依赖准备、部署锁、备份回滚、TLS 健康检查；修复 Linux npm 路径兼容问题。
- 单蛇长矛插件图标及一致的 Codex、Claude、通用插件版本信息。
- 具摘要的合成证据索引、明确保留的失败记录和受控文档基线。

## 下载与安装

- `medcius-V1.0.0.zip`：从发布标签指向的 Git 提交打包的插件目录，解压后为 `medcius/`。
- `SHA256SUMS.txt`：插件 ZIP 的 SHA-256。
- `release-manifest.json`：标签、源码提交、文件大小、条目数和 ZIP 摘要。
- GitHub 自动提供的 Source code：完整仓库，包含部署、模型准备、测试和验证脚本。

插件包不包含模型权重、node_modules、患者记录、运行数据库或密钥。
使用生产路径前，须按仓库中 `plugins/medcius/runtimes/cn-phi-ner/README.md`
准备锁定依赖与独立模型资产。固定模型资产总量为 103,402,382 字节；运行时不会下载。

## 验证与适用边界

发布流水线要求同一源码提交的插件 CI 与凭据扫描成功，并核对三个插件清单与
发布标签版本一致。每次检查的实际结果和回执见该提交的 GitHub Actions。
工程检查、合成脚本完成、研究终点、临床证据及医院验收分别记录，不能相互替代。

80 ms 是指定基准的平均耗时门槛，不是每个请求的保证或所有硬件的性能承诺。
历史超限结果保留。临床使用上限仍为经授权的静默试点；交接、会诊、出院技能的
临床入口继续冻结，江苏分组器为 `NOT_CONFIGURED`，Codex FHIR 工具仍只读。
正式规则包、医院授权、伦理与临床验证要求没有因版本发布而改变。
