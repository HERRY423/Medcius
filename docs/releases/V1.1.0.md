# Medcius V1.1.0

Medcius 为宿主 Agent 提供临床工作流技能、只读数据工具、PHI 防护、来源追溯与审计。V1.1.0 是工程试点版本，首个医院参考工作流为查房前患者演变摘要的静默采集。

## 主要更新

- 晨间病区预计算采用同一资料截止时间，索引记录成功、失败和未处理床位。北京时间 07:00 后停止发起新读取，审计索引按时提交后才报告成功。授权研究复核可从工作清单逐床核对来源证据。
- 患者演变摘要增强了检验时序、来源覆盖、记录更正、实际给药日期及未闭环事项的处理。缺失、冲突或来源不明时保留明确的未知状态。
- 夜班 SBAR、出院资料核对、病案首页与结算清单回放及病程事实包增加了合成回归和来源锚点。交班、会诊和出院技能继续受 P0 冻结策略约束。
- 中文病历抽取增加了断言范围、富文本归一化和来源绑定检查。PHI 运行时增加了本地模型的租户与清单绑定、姓名反例回归和有界 CPU 推理调度。Codex FHIR 接口保持只读。

## 安装与校验

正式发布由 GitHub Actions 从 `V1.1.0` 标签对应的提交构建，产物包括 `medcius-V1.1.0.zip`、`SHA256SUMS.txt` 和 `release-manifest.json`。模型权重和原生依赖需要单独准备。部署步骤见 [部署手册](../../deploy/DEPLOYMENT.md)，模型配置见 [本地中文 PHI 运行时](../../plugins/medcius/runtimes/cn-phi-ner/README.md)。
