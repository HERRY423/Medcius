## 1. 为什么这是 P0（定性）

- 《医疗机构处方审核规范》（国卫办医发〔2018〕14 号）：**第六条**「药师是处方审核工作的第一责任人……医疗机构可以通过相关信息系统辅助药师开展处方审核」；**第八条**「信息系统内置审方规则应当由医疗机构制定或经医疗机构审核确认，并有明确的临床用药依据来源」。
- 这给了 Medcius 合法的存在位置（**信息系统辅助**），且其「医院导入官方语料 + 证据出处门控」设计与第八条的「规则由医疗机构确认 + 明确用药依据来源」直接同构——这是注册叙事的锚点。
- 但「辅助」不等于免证：行业内主流前置审方/合理用药软件普遍以二类医疗器械持证上市 [待核：抽样核实同类产品注册证]。无证进入院内正式审方流程，在医院等级评审与药事检查语境下不可接受。

## 3. 分类界定：正面回答「是不是必须二类证」

### 3.1 纠正问题框架

「审方进院内流程必须二类证」**不是准确的提问方式**。按 2021 年第 47 号通告，真实的风险分布是三层：

| 判定结果 | 条件 | 后果 | 本项目概率判断 |
|---|---|---|---|
| **不作为医疗器械管理** | 处理对象非医疗器械数据（处方/病历文本符合 47 号通告所举「患者主诉等信息」一类）且不用于医疗用途 | 无需注册，但「用于医疗用途」显然满足，此路论证空间极窄 | 低 |
| **第二类** | 属医疗器械但属**非辅助决策**（数据处理/比对，提供临床参考信息） | 省局注册，60 日法定审评，可争取 | **目标类别，需主动论证** |
| **第三类** | 被认定为**辅助决策**（47 号通告明文列举「用药指导」）且算法成熟度低（LLM 在环几乎必然被如此认定） | 国家局审评 + 临床试验路径，36–48 个月量级 | **默认下行风险，必须规避** |

结论：**二类不是「最低门槛」，而是需要靠产品设计+申报策略去「赢得」的结果；真正的悬崖是三类。**

### 3.2 两条论据链（分类界定申请书的骨架）

**论据链 A（我方主张：非辅助决策 → Ⅱ 类）**
1. 处理对象是 HIS/病案系统的**文本记录**（处方正文、出院记录），非医疗器械产生的数据；
2. 核心功能是对药品说明书/医保目录条文的**一致性比对与证据定位**，输出为四选一状态码（PASS / FLAG / INSUFFICIENT_DATA / REQUIRES_PHARMACIST_REVIEW），其中三个去向都是**转人工**；
3. 不向医师/药师生成任何治疗建议文本（《处方审核规范》第六条将此类信息系统定位为「辅助药师」，药师为第一责任人）；
4. 审方规则的依据来源由医疗机构导入并确认（第八条），软件不自行设定医学规则。

**论据链 B（监管可能的反向认定，必须在申请书中预先回应）**
1. FLAG 结果决定处方能否流转 → 实际影响用药行为 → 可能被认定为辅助决策；
2. LLM 参与自由文本理解 → 触发「人工智能医用软件」定义（47 号通告）→ 成熟度低 + 辅助决策 = Ⅲ；
3. 同类产品先例：**已证实**——含前置审方功能的云 HIS 以二类获证（粤械注准20202210206），美康 PASS / 天际健康 / 卫宁健康构成二类持证品类常态，且某医院 AI 准入规范明确要求前置审方应用持证进场（取证见 `EVIDENCE-PRIOR-ART.md`）。

### 3.3 降险架构决策（现在就要锁进代码与文档，因为界定申请书要照此书写）

| 决策 | 内容 | 落点 |
|---|---|---|
| D1 | **判定确定性**：PASS/FLAG 由规则引擎（说明书条文匹配 + 剂量公式 + 相互作用表）产生；LLM 仅做实体抽取与条文引用定位，**不生成结论语句** | `prescription-review` G1–G3 门控已是此结构，需在 SKILL.md 中显式声明「LLM 无判定权」 |
| D2 | **输出封闭性**：输出模板字段固定，禁止自然语言治疗建议；所有非 PASS 强制 `REQUIRES_PHARMACIST_REVIEW` + 药师 `signoff` | 已实现（audit signoff），保持不破坏 |
| D3 | **预期用途措辞**：说明书统一表述为「供药师复核参考的信息系统辅助工具，不出具用药建议，不替代药师审核」 | 注册资料与 README 合规声明保持一致 |
| D4 | **算法可解释**：每条判定附六字段出处（snapshot_hash/source_version 等） | 已实现，是 2022-9 号「核心算法」章节的现成素材 |
| D5 | 若未来引入生成式能力（如审方意见自动起草），**独立成模块、默认关闭、不进入判定链**，避免污染主产品的分类论证 | 新功能准入红线 |

- **合计：Ⅱ 类目标 16–20 个月**（并行充分的前提下）；若被界定为 Ⅲ 类，叠加临床试验后按 36–48 个月量级重排，届时应重新评估产品边界（见 §6）。
- 费用量级（经验区间，**待询价核实**）：QMS 咨询与认证、注册检验、临床评价合计通常在数十万元人民币量级；Ⅲ 类路径显著更高。

## 6. 决策护栏（沿用 v1 并强化）

- 分类界定答复到达前，不向任何医院宣称「可用于正式审方流程」；试点仅以「回顾性研究/工具试用」名义并在协议中写明研究性质。
- 若答复为 Ⅲ 类：**优先收缩产品边界**（例如仅保留编码辅助与病历抽取这两条非辅助决策线进院，审方线退回研究场景），而不是硬闯三年注册周期。
- 样例库（`data_class=sample`）不计入任何注册资料；不用回顾性报告冒充临床试验结论。
- 本文档不构成法律意见；所有 [待核] 项在启动对应 Phase 前必须由注册顾问逐条关闭，并同步更新 `REG-ACTION-TRACKER.md`。
