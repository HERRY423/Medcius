# Medcius 临床评价报告框架与证据边界

> 修订：2026-10-04。此文件是待填充的评价框架，不是临床评价通过报告。
> `clinical_evidence_pass: false`。工程测试、合成回放、伦理编号、哈希或调用者声明均不能独立授予临床通过。

## 1. 产品与首个预期用途

Medcius 是宿主无关的 Agent 插件，提供受约束的工作流技能、只读数据工具、来源追踪、PHI 保护及审计合同。首个参考工作流是查房前患者变化摘要，供具备权限的医生核对原始资料。宿主负责对话与编排，医生负责最终判断；输出不构成诊断、治疗建议或完成的 EHR 写回。

交接班、会诊及其他工作流不能从查房摘要的结果继承验证结论，每个工作流需有单独的预期用途、许可边界与证据计划。

## 2. 当前证据登记

| 证据层 | 可支持的范围 | 当前限制 |
|---|---|---|
| 工程检查 | 指定代码版本下的契约、安全和回归行为 | 以对应运行日志为准；此框架不固定通过数量或百分比 |
| 合成病例评测 | 固定夹具中的统计计算、来源检查和失败行为 | 不是连续医院入组；标签模拟不构成独立医生评分 |
| 真实临床与人因证据 | 需要获批方案、可核验来源、独立评价和签署结论 | 当前文件未包含这类证据，保持 BLOCKED |

多科室回放没有第二名独立评分者，因此不能报告双盲 Kappa=1.00。无锚点、未核验和未仲裁条目必须保留；不能通过剔除这些条目获得“100% 保真”。存在有效引用仅证明可定位来源，不能自动证明正文事实正确。

时间分析器中的四组会话是源码固定的合成参数。其中的节时比例、点击差异和 NASA-TLX 差异仅验证计算路径，不是现场测得的医生收益。简单比较两组遗漏计数不能证明临床非劣效性；不再沿用“节时79.4%”“达成临床非劣效性”或“临床受益大于剩余风险”等结论。

## 3. 评测完整性要求

1. **来源与单位**：记录夹具或受控档案版本、内容哈希、运行版本及冻结时间。区分患者、就诊、候选条目、评分对和观察会话，不能互换分母。
2. **配对完整性**：病例与维度构成唯一键；重复键、预测无金标准、金标准无预测必须显式阻断本次配对评测，不静默剔除。
3. **缺失与弃答**：空样本、缺失测量、未知标签、未完成双侧评分和未仲裁均保留为未知或待处理；不转换为零事件、阴性或一致。
4. **类别与安全**：阳性类别错分计入漏报和误分类；关键点单独统计。FP 与 FN 同时增加不意味着新增一个病例。报告明确实际评分分母及弃答覆盖率。
5. **统计边界**：无分母的比例与无类别变异的 Kappa 不可计算；统计检验不显著不证明一致性或非劣效性。非劣效性需要预先批准的估计对象、界值、样本量与区间分析。
6. **报告状态**：每次运行生成与该输入对应的状态；失败不得保留同一输出位置的旧成功结果。机器字段、报告正文与人工接受状态应一致。

## 4. 两阶段验证计划

### 阶段 A：获批的静默事实质量研究

冻结连续入组规则、患者/就诊与时间边界、来源覆盖要求、候选事实和主要终点。保存受控、不可变、可重放的摘要与证据，经过 PHI 出口保护。由独立评分者评价事实错误、关键遗漏、弃答、未知状态和来源正确性；缺失或有分歧者由第三方处理并保留完整记录。

静默模式下医生不使用输出，因此此阶段不能直接证明使用后的节时、负荷变化或临床结局改善。

### 阶段 B：单独获批的医生可见人因研究

在阶段 A 达到预定门槛且批准展示后，与现行 EHR 工作流进行配对比较。总时间包含查看来源、纠错、接口等待和失败处理；不能仅计摘要生成时间。节省至少90秒可作为候选时间目标，正式方案仍需确认适用人群、基线、统计方法与安全终点。

## 5. 待独立签署的结论

当前能够提出的是工程改进与研究计划。真实准确性、医生收益、风险受益关系和临床准入均未由本文确立。只有在可复核原始证据、完整统计报告和独立负责人员审查后，才可填写相应结论。
