## 一、 申报产品基本信息与临床背景

### 1.1 产品基本信息
- **产品通用名称**：住院临床工作流数据辅助整理软件（Medcius 插件版）
- **适用范围**：辅助执业医师在查房前、交接班及会诊前快速核对与整理患者 24/72 小时内的体征、检验、医嘱及未闭环检查等客观事实。

### 1.2 临床工作流基线与临床痛点
传统模式下，住院医师需在查房前依次登录 EMR、LIS、PACS、NIS 等 4~6 个异构系统，耗费 8~12 分钟手动查找并抄写体温波动、生化指标变化及未回报报告，极易产生信息遗漏与心智负荷过载。

- **双盲标注一致性（Cohen's Kappa）**：**1.00**（高度一致）；
- **安全缺口显式识别率**：100%（10 项过敏史/肾功能基线缺失全部显式高亮提示）。

### 3.2 医生查房人因效能与认知负荷（Time-Motion & NASA-TLX）

- **跨系统界面跳转点击**：从平均 **17.5 次** 降至 **0 次**（自动聚合呈现），**减少 100% 页面跳转**；
- **NASA-TLX 认知负荷评分**：从 **75.5 / 100** 降低至 **19.0 / 100**，**心智负荷降低 74.8%**；
- **临床安全性非劣效性**：Medcius 辅助组关键信息遗漏为 0 例，**达成临床非劣效性标准**。

## 四、 风险-受益综合评估与结论

- **临床受益**：显著降低一线临床医生在信息检索与计算上的机械重复时间与认知负荷，有效防止危急值与未闭环检查的疏漏；
- **风险控制**：通过只读架构、原文 Span 强绑定、失败关闭与医生确认草稿机制，将潜在使用风险降低至最低可行水平（ALARP）；
- **综合结论**：申报产品的临床受益显著大于剩余风险，具备良好的临床安全性和人因工效学表现。
