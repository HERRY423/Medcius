# 临床研究伦理审查申请框架与去标识化操作规程 (IRB-PROTOCOL-FRAMEWORK)

> **版本**：v1.0 (2026-08)  
> **适用范围**：Medcius 临床工作流插件在合作医疗机构开展的前瞻性影子研究（Shadow Study）与 Time-Motion 观察研究。  
> **合规性质**：医疗机构伦理委员会（IRB / IEC）标准报件参考框架。

---

## 一、 研究背景与目的

### 1.1 研究背景
现代住院病区临床医生每日需在 EMR、LIS、PACS、NIS 等多个割裂的院内信息系统间手动查找、核对患者过去 24/72 小时内的体征极值、检验动态、医嘱变更与未出报告，带来繁重的信息检索负担与潜在遗漏风险。Medcius 作为受约束的一线临床工作流插件，通过只读连接器与结构化演变计算，提供带原文 Span 证据绑定的查房前信息整理。

### 1.2 研究目的
1. **主要终点（安全性与准确性）**：评估 Medcius 在静默模式下提取临床事实与未闭环事项的灵敏度、特异度及原文证据绑定率（目标：≥ 98.0% 且零伪造事实）；
2. **次要终点（人因工效学与效率）**：评估插件对医生查房准备时间（秒）、跨系统界面切换次数及认知负荷（NASA-TLX）的改善幅度；
3. **探索性终点**：验证多科室（心内科、呼吸科、肾内科等）间规则包的跨病区适配性。

---

## 二、 研究设计与受试者保护

### 2.1 研究设计
- **研究类型**：前瞻性、观察性、单/多中心自身前后对照影子研究（Shadow Study）；
- **干预性质**：**非干预性（Non-interventional）**。插件运行于静默只读模式或辅助生成待核草稿模式，**严禁自主下达医嘱、严禁自动写回 EHR、严禁替代临床决策**；
- **责任主体**：患者的主管医师与值班医师承担全部诊疗决定与文书签署责任。

### 2.2 知情同意豁免申请（Waiver of Informed Consent）
依据《涉及人的生命科学和医学研究伦理审查办法》第三十二条，申请豁免受试患者知情同意：
1. 研究属于利用已有的或常规诊疗中产生的临床数据，不增加患者任何身体、心理或经济风险；
2. 研究仅对数据进行院内瞬时内存脱敏处理与统计分析，不影响患者正常的诊疗计划与权益；
3. 豁免知情同意不会对受试者的权益造成不利影响。

## 三、 数据安全与去标识化操作规程 (De-identification SOP)

```text
[ 医院内网数据源 ]
  (EMR / LIS / PACS / NIS)
        │ 
        ▼ (mTLS + 内网只读连接器)
[ Medcius 院内前置机出口守卫 (PHI Guard) ]
        │  • 姓名假名化 (HASH 映射表仅存院内 KMS 内存)
        │  • 身份证号 / 手机号 / 医保卡号正则强剔除
        │  • 就诊号与床号散列隔离
        ▼ (脱敏后内存数据)
[ 确定性演变计算与证据绑定引擎 ]
        │ 
        ▼ (SHA-256 审计链哈希记录)
[ 临床医生双盲标注与仲裁工作台 ]
```

### 3.1 严格执行的脱敏标准
- **直接标识符（Direct Identifiers）**：患者姓名、身份证号、家庭住址、联系电话、银行卡号、生物识别信息在进入分析引擎前必须 100% 假名化或擦除；
- **准标识符（Quasi-identifiers）**：出生日期泛化为年龄（岁），精确就诊时间在研究导出日志中偏移固定随机时区；
- **物理不出院原则**：原始病历文本仅存在于院内物理前置机内存瞬时态，导出至研究分析集的仅包含统计指标与脱敏标注结果。

## 四、 质量控制与双盲标注 SOP

### 4.1 独立双盲标注流程
1. **医生 A（试验组/插件辅助）**：使用 Medcius 辅助界面核对查房事实并确认；
2. **医生 B（对照组/独立人工）**：在不查看 Medcius 输出的情况下，独立手动翻阅 EHR 完成病历核对；
3. **独立第三方（主任医师/PI）**：对医生 A 与医生 B 的标注差异进行最终仲裁，计算 Cohen's Kappa 一致性系数。

### 4.2 质控停止线（Stopping Rules）
若在研究过程中出现以下任意情况，立即暂停试验并启动根本原因分析（RCA）：
- 出现 1 例因插件提取错误导致的严重误导倾向（即便是静默模式）；
- 算法事实提取敏感度低于 90.0%；
- 发现任何未经脱敏的敏感 PHI 数据流向院外日志或未授权存储。

1. 临床研究方案（本文件及详细实施细则）；
2. 主要研究者（PI）简历与 GCP 证书；
3. 利益冲突声明（COI）；
4. 数据安全与隐私保护承诺书（含网络安全等保证明）；
5. 软件安全性测试与合成验证通过报告（`run-all-checks.mjs` 绿灯证据）。
