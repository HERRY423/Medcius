## 本地公钥配置契约

设置 `MEDCIUS_IDP_CONFIG` 为部署者控制的本地JSON文件路径。结构如下，值均须由医院部署人员填写：

```json
{
  "allowedAudiences": ["<API audience>"],
  "allowedTenants": ["<hospital tenant>"],
  "issuers": [{
    "issuerUrl": "<exact trusted issuer>",
    "tenantId": "<hospital tenant>",
    "staticKeys": {"<kid>": "<PEM public key>"}
  }]
}
```

每次验证重新读取配置以反映撤销/轮换；密钥来源必须由部署者管理。请求中的issuer/kid只能选择已有受信条目，不触发下载。没有实施自动JWKS抓取。
