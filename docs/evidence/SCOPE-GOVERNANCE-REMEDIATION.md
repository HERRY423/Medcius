## 8. 可执行门禁

- 工程检查必须同时满足退出成功与明确的结果标记；缺少证据、超时或信号终止均失败。Node 测试文件要求非零用例与零失败。报告任务只记 EXECUTED / NOT_ASSERTED，不将报告生成解释成临床终点通过。
- 每次全量运行写唯一编号的机器记录和 latest 索引，包含命令、耗时、预期证据、输出摘要与分层状态。原始失败运行保留。
- JSON 检查对 MCP 配置、插件清单及专科规则包实施映射契约与语义校验；尚未映射的文件明确标 SYNTAX_ONLY。自有校验器是有限方言，拒绝未知校验关键字，不宣称完整支持 JSON Schema。
- QMS 的 11 项机器检查进入现有 CI 入口。m03 改为定向边界回归，消除与全量检查的递归。m01 核对需求结构及 ID 唯一性，m02 核对风险引用，m05 执行合成审计篡改/签名负例，m06 检查当前受控基线；均不冒充完整体系审核。
- 无效/空审核子集被拒绝；CLI 人名声明标 claimed_unverified，不能取得正式审核通过；每次输出使用唯一文件名，避免覆盖旧记录。
- `deploy status` 的 quick_gate 实际运行契约校验；负例证实无效配置会失败。
- PHI 兼容类调用统一检测与转换实现，保留可选上下文规则；无固定默认盐。此措施降低实现分叉，不能证明脱敏检测无遗漏。
- 共享深冻结工具、规则摘要实现与撤销/错误记录的协调判定；既有输出一致性、生命周期及规则回归通过。成功模型调用在 finally 清除超时计时器；30 秒计时器残留的独立子进程负例通过，真实超时拒绝仍保留。
