# 面向医生的界面收敛

## 阅读路径

默认页面围绕三个步骤：确认患者 → 查看当前任务资料 → 就地展开依据。固定患者栏展示患者与就诊标识；报告单独标明资料截止时间及“本机时间”，不会把生成时间当成检查发生时间。

四个一级入口：查房准备、交接班、会诊准备、出院资料。每次只展示当前任务所需输入。查房使用变化、待跟进、资料缺口三块导航；数量用于定位资料，不是病情评分。会诊先显示诉求与专科相关资料；交接保留责任状态、未完成事项和来源医生预案；出院保持结果、用药衔接、后续安排三组独立状态。

首屏移除 JSON 数据编辑、数据库字段树、签核摘要和验签操作。接入与辅助工具位于折叠区；签核是否可用来自服务端权限，研究模式不自动开放。所有界面维持研究参考标识，HIS 静默页与既有临床门禁未改为开放展示。

## 依据与信息密度

来源字段先按中文名称呈现，附加技术字段在二级展开中保留。空值显示“未提供 / 未知”，不统一写成“未提及”。数组为空仍保留输入范围限制。检验值保留单位；缺单位不补造。

常见列表先显示有限条目并注明剩余数量，完整内容可展开。会诊来源危急标记仍由原引擎摘要决定展示，不因普通条目数量上限隐藏。已经在检验/影像行展示的同版本修订不再额外重复成另一张变化卡，完整版本历史仍可查。继续显示撤销、冲突、来源不可用和范围未知，不将“少显示”误作“无异常”。

用药衔接分别提供衔接记录、在院用药、出院用药依据入口。出院资料字段齐备始终不表示可以出院。预案、责任确认和结果复核均沿用来源状态；页面浏览不触发完成事件。

## 操作状态

更换患者、就诊、资料来源、任务、时间窗、会诊诉求或补充来源，立即撤下旧报告及签核绑定。请求具有当前输入指纹和递增序号；即使底层请求忽略取消，过期结果也不能覆盖当前页面。失败时清空旧报告并给出可读提示。会诊必填项为空、JSON 格式错误和患者身份矛盾都不继续计算。

接口回传患者/就诊元数据供页面核对，查房接口新增显式上下文检查。元数据用于定位，不作为临床批准或额外的签名授权。来源数据、签核与权限仍以服务端合同为准。

## 本地体验与验证

运行 `node scripts/demo-doctor-workstation.mjs` 生成 `out/doctor-workstation/synthetic-preview.html`。这是与实际工作台使用相同控制器和渲染器的离线合成预览；可切换三张合成床位和四类任务。离线会诊与时间窗仅接受预置诉求/24小时；变更后明确拒绝，不悄悄沿用旧结果。任意诉求需使用本地实际接口。

`tests/test-doctor-ui.mjs` 已纳入全量回归：覆盖上下文失效、迟到响应、失败恢复、必填与来源解析、签核禁用及文本转义。实际浏览器使用隔离无界面 Edge 与本机已有 Playwright 运行库，验证四类流程、依据展开、患者切换、诉求编辑、迟到响应、网络失败和 390px 窄屏。截图和浏览器结果位于 `output/playwright/`。

本轮实施范围为共享工作台参考界面及其只读接口，不将 Medcius 改成独立临床平台；旧版侧栏保留为既有参考适配器，HIS 静默页仍按原门禁运行。

## 尚需医生验证

视觉和工程检查不证明认知负担已经降低。下一阶段应以合成病例开展医生任务走查，记录找到某次更正结果、找到当前待办、辨认接班是否完成、发现出院安排责任人缺失的用时和误判，重点观察是否误将“已查看”“字段齐备”当作临床完成。真实患者验证仍需独立授权与部署边界。
