# 中文自由病历抽取改进（工程记录，供审阅）

本次完成规则解析改进和可调用的受控候选抽取接口。工程测试支持这些有界行为；真实医疗 LLM 的召回率、真实病历泛化及医师复核收益均未建立。模型候选不自动升级为临床事实、诊断、编码或判定。

## 图中问题的核实

旧 `noise-fixture-v1` 的 73.3% / 70.0% 是 **10 份合成病历 × 3 个变体的全字段原文匹配率**，不是实体级 precision 或 recall。缩写组的 8 次失败均为评分器要求完整中文名称，而原文已写成 `LC术` 或 `急阑尾炎`。此外，三个 seed 并非三个独立患者，因此原报告的区间不能解释为患者总体泛化区间。旧报告保留在原路径，新诊断单独记为 v2。

同一旧评分器下，空白粘连由 29/30 改善到 30/30；缩写仍为 22/30，组合仍为 21/30。新增加的词法别名诊断分别为 30/30、29/30；这两个数字用于区分评分名称不一致与剩余失败，**不能作为模型召回提升的前后对比**。组合组剩余失败保留了 OCR 将“人工”损坏为“入工”的原始问题，没有猜改字符。

## 已实现的行为

- 规则作用域：口语否定、后置“均无”、问号/英文句号边界、家属主体与时间切换分别处理；保留每个片段与 cue 的 UTF-16 坐标。转折不再把家属自动改成患者。计划/未实施手术不能填入已实施字段；过敏史的相反证据不由一句总否认覆盖。
- 原文与术语：`value/span` 保留原文；确定的词法别名单列，`PE/RA/MS` 无默认展开。粘连诊断编号、无标题病程、多个临床章节都可读取。全角数字、明确指数单位和比较符得到支持；OCR 残缺数字、数值区间与数值溢出不截取成貌似可靠的点值。
- 候选接口：`createCnNoteExtractor` 默认 `rules_only`，显式 `hybrid` 才调用管理过的客户端；患者/就诊/机构/来源版本/带时区的时间先核对，本地 PHI Guard 先于解析和模型上下文执行。
- 模型限制：固定 prompt pack、严格 JSON、来源哈希和每次请求 ID、原文坐标、候选上限、总时限与并发限制；显式关闭工具调用。任何新增候选都进入 `review_candidates`，即便与规则一致也不自动入诊断或判定链。模型失败有明确状态；隐私防护失败拒绝整个操作。
- 人审证据：每项候选同时提供摘录和包含否定/时间/主体的句段锚点；规则冲突、上下文截短和候选间冲突单独显示。重复原文按位置保留；来源版本变化后锚点失效。`span_verified` 只证明出处，不证明语义。

接入代码：[抽取接口](../../plugins/medcius/lib/cn-note-extraction.mjs)、[模型候选契约](../../plugins/medcius/lib/cn-note-candidate-contract.mjs)、[接入与回退说明](../../plugins/medcius/skills/clinical-note-extract/references/controlled-extraction.md)。

## 验证范围

新增 22 条合成语法开发样例：完整匹配从 **10/22 到 22/22**；逐片段三轴完全匹配从 26/40 个预期片段到 40/40。该集合在本次开发中使用，不能当作独立留出评估。前后使用同一份 fixture，摘要一致，见[改进前](verification/2026-11-14-cn-note/assertions-before.json)与[改进后](verification/2026-11-14-cn-note/assertions-after.json)。

自动检查覆盖伪造引文、上下文删减、错误主体/时间、过期来源、重放、错误 schema、超大输入/回复、隐私内容、并发占用、超时和复制残留；另以实际本地 ONNX NER 验证 A/B 两种拓扑的候选链路。医疗语言模型 transport 在这些测试中为合成替身；实际执行的是 NER，不能据此声称真实 LLM 有效。

最终测试状态、命令、运行回执与代码摘要见[验证清单](verification/2026-11-14-cn-note/verification.json)。历史失败尝试也保留；模型目录、离线缓存或本机服务连接不足时不会改成跳过通过。性能参考环境检查与临床证据另列，不以功能通过代替。

## 下一步与改判条件

可以立即在批准的院内环境按接入说明调用 `rules_only` 或注入指定模型做 `hybrid` 回放。要把结论从“工程链路已验证”升级为“召回提升”，下一项有决策价值的工作是对同一批独立、源文本先行标注的病历比较规则与真实模型，按患者划分开发/评估集，同时报告候选召回、误报、三轴错误、弃答和复核时间。若召回提高而误报或复核负担不可接受，继续保留候选审阅模式或回退 `rules_only`；只有这些终点共同达到预设条件，才支持扩大使用范围。所需成本是批准的标注病历、医师审阅时间和指定模型的推理预算，本次尚无可据以报价的部署配置。
