## 整合范围

- 中文断言作用域、测量抽取、CDA 身份与时间、站点视图映射、医嘱执行和 PACS 来源链接。
- 生产路径的异步双轨 PHI：会话词典与固定本地 CPU NER，覆盖 HIS、MCP、文档、审计及模型输入输出；失败继续阻断。
- NER 独立批处理、逐值等价性、请求隔离、并发和原生故障回归；模型权重、阈值及固定 80 ms 门槛未因本次整合调整。
- 具版本的编码映射、病案证据核对和专科参考资料；江苏分组器仍为 `NOT_CONFIGURED`，不补选统筹区或规则。
- 离线依赖准备、真实 CPU 推理就绪探针、部署锁、备份回滚、TLS 健康检查及新增测试。
- 单蛇长矛图标：512×512 展示、128×128 输入区，Claude 约定入口使用相同 512×512 图稿。
- 三种插件清单、镜像版本、README 和 18 份受控文档统一版本；运行时 API/适配器读取主清单版本，避免独立硬编码。受控文档递增修订号并更新内容摘要，仍为 `DRAFT_UNAPPROVED`。
- GitHub 检查准备锁定的 Node/Python/NER 依赖和具摘要的模型资产，保存失败及成功回执；本地两份具名合成摘要复制到可提交目录，修复证据索引断链。
- 补充第三方来源记录、凭据/数据库/模型忽略规则，并固定具摘要文件的 LF 换行。历史记录不回写新版本；日期文档中个人主目录路径已去标识化，原有失败状态保留。

全量命令为 `node scripts/run-all-checks.mjs`。本机为 Windows x64、Node
24.13.0、14 个逻辑 CPU；测试使用独立临时数据目录，模型来自预先准备的本地目录，
npm 使用预先准备的离线缓存。最终运行时间和逐项命令见回执；不把退出 0 等同于临床研究终点通过。

两次性能观测存在差异，本次没有识别其原因；保留首轮超限及最终 p95 超过 80 ms
的结果。80 ms 是原有平均耗时门槛，不能据最终平均值承诺每个请求或其他硬件的性能。
没有为了通过而改变预算、fixture、迭代数或模型精度。

初次直接运行定向测试时未配置隔离数据目录，遇到数据库访问和本机回环权限失败；
切换到隔离目录后，部署测试还曾退出 2；该次未指定预置离线缓存。
完整运行显式使用既有模型与离线缓存，部署测试在两轮全量中均通过。
用户约定的外部 plugin-creator Python 路径仍缺失；本轮使用仓库内固定来源、
先核对完整性再执行的校验器，没有声称运行了不存在的路径。

回执中的 `log_path` 是本地相对路径，原始日志保存在被忽略的 `out/`，没有作为
可公开的患者记录上传。公开回执保留命令、退出码、时间、分类、输出摘要与失败；
模型权重、node_modules、数据库、密钥和本机证据缓存不进入此次提交。

历史凭据扫描的首次尝试遇到 Git textconv 执行失败，即使扫描器退出 0 也未视为
