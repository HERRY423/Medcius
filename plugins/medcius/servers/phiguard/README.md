# mcp-server-phiguard — PHI 卫士（Medcius-original）

无状态 MCP 服务器：在自由文本进入**日志 / 审计链 / 导出 / 模型上下文**之前做 PHI 检测、脱敏与稳定假名化。

## 工具

| 工具 | 说明 |
|---|---|
| `scan` | 检测：18 位身份证（GB 11643 校验位）、手机号、邮箱、标签病历号（住院号/门诊号/病历号/登记号）、标签姓名（患者：/姓名：…） |
| `redact` | `mode=mask`（保留首尾）或 `mode=hash`（`[type:sha8]`） |
| `pseudonymize` | 稳定假名化 `[PSN:hmac8]`，同值同 token；盐：参数 > `CLAUDE_MEDCIUS_PHI_SALT` > ephemeral（重启即变，会警告） |
| `status` | 盐来源、算法版本、覆盖与局限 |

## 已知局限（诚实边界）

- **无标签的裸姓名不检测**——避免误报也不冒充全覆盖；输入侧应尽量结构化。
- 固定电话/住址/银行卡未覆盖。
- 这是纵深防御的一层，不替代磁盘加密、访问控制与传输安全。

## 与审计链的强制联动

`mcp-server-audit` 的 `record_event` 会拒绝含身份证/手机号原文的记录（正则守卫），错误信息会指引先调用本服务。隐私设计为**默认强制**而非文档倡议。
