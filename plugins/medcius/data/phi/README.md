# Chinese PHI phonetics

Generated by `scripts/build-cn-phi-phonetics.mjs` from pinyin-pro 3.29.5 (MIT).
Tone-free character readings, including heteronyms, in U+3400–4DBF and U+4E00–9FFF.
Used only to match the active session’s known names; not a general name recognizer.
Homophone matches can over-redact; dialectal and out-of-table variants remain uncovered.
Names and matching results are never added to this public table.
