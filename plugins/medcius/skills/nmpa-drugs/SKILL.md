# NMPA 药品注册查询（NMPA Drug Registry）

查询中国国家药品监督管理局（NMPA）的药品注册信息。中国药品监管体系与美国FDA不同，药品注册由国家药品监督管理局统一管理，批准后获得药品批准文号。

## 第一步：明确查询需求

**确定查询维度：**
1. **药品注册信息** — 批准文号、注册分类、生产企业、批准日期
2. **药品说明书** — 适应症、用法用量、不良反应、禁忌、注意事项
3. **药品分类** — 处方药/非处方药（OTC）、中药/化学药/生物制品
4. **药品标准** — 中国药典（ChP）、国家药品标准
5. **特殊药品** — 麻醉药品、精神药品、医疗用毒性药品、放射性药品

**查询方式：**
- 按**药品名称**（通用名或商品名）查询
- 按**批准文号**查询（如"国药准字H20000001"）
- 按**生产企业**查询

## 第二步：查询NMPA药品注册信息

使用 NMPA 药品注册 MCP 连接器查询：

- `search_drugs` — 按药品名称、批准文号或生产企业搜索
- `get_drug_detail` — 获取药品注册详细信息（批准文号、注册分类、规格、剂型）
- `get_drug_label` — 获取药品说明书
- `get_drug_classification` — 查询药品分类（处方药/OTC、中药/化药/生物制品）
- `validate_drug` — 验证药品批准文号有效性

**查询要点：**
- 药品名称使用**通用名**（如"阿托伐他汀钙片"），商品名（如"立普妥"）作为补充
- 批准文号格式：**国药准字** + 字母（H=化学药，Z=中药，S=生物制品，J=进口分装）+ 8位数字
- 进口药品使用**进口药品注册证号**（如"国药准字J20150001"或"注册证号H20150001"）
- 中药分为**中成药**和**中药饮片**，注册管理不同
- 生物制品包括**疫苗、血液制品、细胞治疗产品**等，监管更严格

## 第三步：输出药品注册信息

输出格式：

```
【药品注册信息】
药品名称：阿托伐他汀钙片
商品名：立普妥
批准文号：国药准字H20000001
注册分类：化学药品
药品分类：处方药
生产企业：辉瑞制药有限公司
批准日期：2000年1月1日
规格：20mg/片
剂型：片剂

【药品说明书摘要】
适应症：高胆固醇血症、混合型高脂血症
用法用量：口服，一次20mg，一日1次
不良反应：肌痛、肝功能异常、胃肠道反应
禁忌：活动性肝病、妊娠期妇女
注意事项：用药期间定期监测肝功能

【监管提示】
该药品为处方药，需凭医师处方购买使用。
```

## 注意事项

- **批准文号有效期**：药品批准文号有效期为5年，到期需再注册
- **药品召回**：查询时注意是否有药品召回公告
- **仿制药一致性评价**：通过一致性评价的仿制药在质量和疗效上与原研药等效
- **中药保护品种**：部分中药品种受《中药品种保护条例》保护
- **不替代官方答复**：本技能提供的药品信息仅供参考，最终以NMPA官网和药品说明书为准
