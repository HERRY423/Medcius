# 国家医保接口：字段语义对照

本文件只做**语义对照**，不实现医保报文，不代替《国家医疗保障信息平台接口规范》原文。交易号、报文和测试环境以医院信息科提供的**当期规范**为准。

Medcius 的产出能映射到结算清单与费用上传字段；**不能**代替医保办审核或分组器。

## 1. 对照范围

| Medcius 产出 | 对应业务 | 不对应 |
|---|---|---|
| `clinical-note-extract`（china-inpatient） | 结算清单诊断/手术/过敏/体征的**原文** | 不产生编码、不回写 EMR |
| `nhsa-coding` | 结算清单诊断码、手术操作码（医保版） | 不是 CCHI、不是临床版 ICD-10 病案首页混用 |
| `prescription-review` | 医嘱/处方合理性辅助，不上传费用 | 不生成医保结算报文 |
| `nhsa-policy` | 目录准入与支付限制依据 | 不计算个人报销额 |

## 2. 医疗保障基金结算清单 ↔ 抽取/编码

依据《医疗保障基金结算清单填写规范》栏目（名称以当期规范为准）：

| 结算清单栏目 | 来源技能 | Medcius 字段 | 填写约束 |
|---|---|---|---|
| 入院诊断 | extract → coding | `admission_diagnosis` 原文 → 医保版 ICD-10 | 不确定诊断（疑似/待查）不编码；编码须完整可结算长度 |
| 出院主诊断 | extract → coding | `discharge_diagnosis_primary` | 导致本次住院的主要疾病；不可作主诊断的编码不得作主诊断 |
| 出院其他诊断 | extract → coding | `discharge_diagnosis_other` | 仅本次诊治的合并症/并发症；既往未处理不列入 |
| 手术及操作 | extract → coding | `procedures` | **医保版手术操作分类（ICD-9-CM-3 基础）**；CCHI 不进此栏；「拟行」不填 |
| 过敏史（病历侧） | extract | `allergy_history` | 否认须保留否定；家族过敏不是患者过敏 |
| 入院病情 | 人工/病案 | 不由模型编造 | 有 / 临床未确定 / 情况不明 / 无 — 以病案首页为准 |
| 离院方式、住院天数 | 病案/HIS | 本插件不抽 | 不对结算清单其他栏目做推断 |
| 诊断代码版本 | coding 出处字段 | `code_system` `code_version` `effective_date` | 版本未知则 `validation_status` 不得为 valid |

每个编码必须带齐：`code` / `code_system` / `code_version` / `effective_date` / `retrieved_at` / `source` / `validation_status`。缺版本的码不能当作可上传结算码。

## 3. 编码体系不得混用

| 实体 | 结算清单用 | 不用 |
|---|---|---|
| 疾病诊断 | 医保版 ICD-10 | 临床版 ICD-10（病案首页）、ICD-10-CM（美国） |
| 手术操作 | 医保版手术操作分类 | CCHI、ICD-10-PCS |
| 药品 | 医保药品分类与代码 | 商品名、医院内部码（除非已对照） |
| 医用耗材 | 医保医用耗材分类与代码 | 厂商型号单独充当医保码 |
| 医疗服务项目 | CCHI（立项/收费） | 填进结算清单手术操作栏 |

## 4. 接口对接纪律（本插件不做的事）

1. **不发送医保交易。** 挂号、门诊结算、住院登记、出院结算、清单上传、目录下载均由医院医保接口完成。
2. **不编造人员参保状态、余额、异地备案。** 属经办系统实时数据。
3. **不把样例库（`data_class=sample`）用于真实结算。**
4. **映射表由信息科维护。** 本文件只提供语义；字段英文名、节点路径以当期 XSD/报文为准。
5. **远端托管医保 API 不是数据源。** 编码与目录只来自本地 `china-codes` 或官方公布文件。

```
出院主诊断 | … | … | … | … | …
手术操作 | … | … | … | … | 非 CCHI

【本插件未覆盖】
人员参保、费用明细、DRG/DIP 分组、电子凭证、异地备案 — 需医保办/HIS。
```
