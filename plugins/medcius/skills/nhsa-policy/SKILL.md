# 国家医保政策查询（NHSA Policy）

查询中国医疗保障政策，为医保经办、医院医保管理和临床决策提供政策依据。中国医保体系实行"基本医疗保险+大病保险+医疗救助"三重保障，政策由国家医保局制定框架、各省市具体实施。

## 第一步：明确政策查询需求

**确定查询维度：**
1. **药品目录** — 国家医保药品目录（甲类/乙类/丙类），谈判药品，集采药品
2. **诊疗项目** — 医保诊疗项目目录（甲类/乙类/丙类）
3. **医用耗材** — 医保医用耗材目录
4. **支付标准** — DRG/DIP付费标准、按病种付费、按人头付费
5. **报销政策** — 起付线、封顶线、报销比例、门诊统筹、门诊慢特病
6. **异地就医** — 跨省异地就医直接结算政策
7. **特殊人群** — 职工医保、居民医保、大病保险、医疗救助

**明确参保地：** 中国医保政策以省级（直辖市）为单位实施，同一药品在不同省份的报销政策可能不同。必须确认参保地（如"北京市"、"广东省"）才能给出准确答案。

## 第二步：查询国家医保政策

**药品目录类问题**：使用**国家医保药品目录 MCP 连接器**（`nhsa_drug_catalog`）查询：
- `get_drug_catalog` — 按药品通用名查询目录分类（甲类/乙类/丙类）、医保支付标准、限定支付范围
- 连接器不可用时，不得凭记忆编造目录分类，改用联网检索官方目录并标注文件版本

**报销比例、DRG/DIP、门诊慢特病、异地就医等政策问题目前没有专用 MCP 连接器**：
- 优先**联网检索官方来源**：国家医疗保障局官网（www.nhsa.gov.cn）、国家医保服务平台、参保地省级医保局官网；引用时给出文件名称、文号与发布时间
- 凡涉及**数字**（起付线、封顶线、报销比例、DRG/DIP 权重与费率、集采价格）必须来自可引用的官方文件原文，否则标注"待核"，**禁止**凭印象给出数值
- 查不到或版本不明时，明确告知："政策具有地区差异和时效性，请以参保地医保局最新文件为准"，必要时建议咨询参保地医保局或医院医保办

**查询要点：**
- 药品查询使用**通用名**（如"阿托伐他汀钙片"），不是商品名（如"立普妥"）
- 政策文件按**发布时间**区分版本，必须确认查询的是最新版本
- 谈判药品有**协议有效期**，过期后按普通乙类药品管理
- 集采药品有**中选价格**和**约定采购量**，与普通药品报销政策不同

## 第三步：结合地方政策

国家政策是框架，各省市有实施细则。查询国家政策后，**必须**结合参保地的地方政策：

- 各省医保局发布的**医保目录调整文件**（在国家目录基础上增补/调整）
- 各省的**门诊慢特病病种目录**和**待遇标准**
- 各省的**DRG/DIP实施细则**（分组方案、权重、费率）
- 各省的**异地就医备案**和**直接结算**流程

地方政策数据没有专用 MCP 连接器，无法从连接器获取时，明确告知用户"国家政策如下，地方政策请咨询参保地医保局或医院医保办"。

## 第四步：输出政策依据

输出格式：

```
【政策依据】
文件名称：《国家基本医疗保险、工伤保险和生育保险药品目录（2024年）》
发布机构：国家医疗保障局
发布时间：2024年11月

【查询结果】
药品：阿托伐他汀钙片
目录分类：乙类
医保支付标准：限价支付，超出部分自付
限定支付范围：高胆固醇血症、混合型高脂血症

【地方政策提示】
参保地：北京市
北京市医保局对该药品的报销比例为：在职职工70%，退休人员80%
（地方政策请以北京市医保局最新文件为准）
```

> **输出骨架说明**：以上为格式示意——其中所有文件名称、发布时间与具体数值（报销比例、限定支付范围等）**都必须替换为本次查询中可引用的官方数据**；未查到确切数值时只给出类别与规则，不保留具体数字。

## 注意事项

- **政策时效性**：医保政策每年调整，必须确认查询的是最新版本
- **地区差异**：同一药品在不同省份的报销政策不同，必须明确参保地
- **限定支付范围**：药品目录中的"限定支付范围"是医保报销的前提条件，超出范围不报销
- **谈判药品**：谈判药品有协议有效期，过期后按普通乙类管理
- **不替代官方答复**：本技能提供的政策信息仅供参考，最终以国家医保局和参保地医保局的正式文件为准
