# 国家医保政策查询（NHSA Policy）— 四层治理模型

中国医保治理**不是**"国家目录 + 各省自己的目录"。药品目录由国家统一制定并动态调整（地方增补品种已消化完毕），省级层面做的是**待遇落地**，不是目录增补。因此查询必须走四层链，且**目录问题与"报销多少"必须解耦**：

```
国家目录 (National formulary)
→ 国家支付限制 (National payment restriction)
→ 省级待遇/支付落地 (Provincial benefit/payment implementation)
→ 患者个体资格 (Patient-specific eligibility)
```

**一个药在目录中，只代表它有资格被支付；并不等于某位患者某次使用必然按固定比例报销。** 实际报销是四层条件的叠加结果，缺一不可。

## 第一步：明确查询需求

- 问清：药品/项目**通用名**、**参保地（省/市）**、**参保类型（职工/居民）**、**就医类型（住院/门诊/门诊慢特病）**——缺了后三层的患者个体信息，答案最多只能到 Layer 3
- 确定查询维度：药品目录 / 诊疗项目 / 医用耗材 / DRG-DIP / 门诊慢特病 / 异地就医

## 第二步：按四层逐层查询

### Layer 1 — 国家目录（准入）

该药品/项目是否在**国家目录**？类别（甲类/乙类/谈判药品）？

- 用**国家医保药品目录 MCP 连接器**（`nhsa_drug_catalog`）的 `get_drug_catalog` 按通用名查询
- 连接器不可用 → 联网检索官方目录并标注文件版本；**不得凭记忆编造目录分类**
- 这一步只回答"是否准入、什么类别"，**不回答报销比例**

### Layer 2 — 国家支付限制（可支付情形与价格上限）

目录内 ≠ 无限制。必须核对国家层面的支付限制：

- **限定支付范围**（如"限高胆固醇血症、混合型高脂血症"）——超出适应症不支付
- **医保支付标准**（限价支付，超出部分自付）
- **谈判药品协议有效期**——过期按普通乙类管理
- **集采中选价格**与约定采购量

### Layer 3 — 省级待遇/支付落地（该省怎么付）

参保地省级医保局的**待遇细则**——注意：**药品目录国家统一，省不做目录增补**；省层面调整的是支付待遇：

- 报销比例（在职/退休、职工/居民分档）、乙类先行自付比例
- 起付线、封顶线
- **门诊慢特病病种目录与待遇**（药品能否按慢特病待遇支付，取决于病种认定）
- **DRG/DIP 本地分组权重、费率**
- 地方数据没有专用连接器 → 联网检索省级医保局官网文件；**凡数字必须可引用省级文件原文**，否则标"待核"

### Layer 4 — 患者个体资格（这位患者这次能报多少）

最终报销还取决于患者个体条件，**通常需医保经办系统实时查询或人工核实，模型不得编造**：

- 参保类型（职工/居民/生育等）
- 就医类型（住院/门诊/门诊慢特病）及**慢特病/特药备案状态**
- 年度内起付线是否已累计达到、封顶余额
- **异地就医备案状态**（备案后直接结算与不备案的区别）
- 药品是否符合该患者的限定支付范围（适应症）与开具条件
- 无法确认时，明确告知"该层需医保经办/医院医保办核实"，**不给具体数字**

## 第三步：输出政策依据（分层呈现，标注各层确认状态）

输出格式：

```
【药品】阿托伐他汀钙片（通用名）｜ 参保地：××省××市 ｜ 参保类型：职工/居民

L1 国家目录：乙类 ✓（来源：国家医保药品目录连接器 / 《国家医保药品目录（20XX年）》）
   限定支付范围：高胆固醇血症、混合型高脂血症

L2 国家支付限制：医保支付标准＝限价支付；谈判药协议期至 YYYY-MM-DD
   ⚠ 超出限定支付范围的适应症不支付

L3 省级待遇落地：××省在职职工报销比例 XX%（来源：省医保局文件＋文号）
   起付线/封顶线：XXX / XXX
   ⚠ 药品目录由国家统一，本省无目录增补；省层面调整的是支付待遇

L4 患者个体资格：需核实——①该患者是否为门诊慢特病认定病种？②异地就医备案状态？
   ③年度起付线是否已累计达到？ → 该层需医保经办/医院医保办确认，无法给出固定数字

【结论】该药在目录内（L1✓），但能否报销、按多少比例，取决于 L2 限定支付范围、
L3 省内待遇、L4 患者个体条件。不能仅凭"在目录中"断言"必然按 XX% 报销"。
```

> **输出纪律**：每一层标注状态——确认 ✓ / 待核 ⚠ / 需经办核实。数字只出现在可引用官方文件的层；L4 一律不给具体数字。

## 核心原则（不可妥协）

1. **在目录 ≠ 必然按固定比例报销** —— 目录是准入，报销是个体化结果，中间隔着 L2/L3/L4
2. **目录问题与"报销多少"必须拆开回答** —— 先答"是否准入、什么类别、什么限制"，再答"该省待遇"，最后"该患者能否"
3. **药品目录国家统一，省不增补** —— 不要建模成"各省自己的药品目录"
4. **数字纪律** —— L3 数字必须可引用省级文件；L4 不给数字、标注需经办核实
5. **不替代官方答复** —— 最终以国家医保局和参保地医保局的正式文件为准

## 注意事项

- 政策时效性：目录每年调整、谈判药协议期、省级文件更新——必须确认最新版本
- 地区差异：以参保地（省/市）为基准，不可跨省套用
- 限定支付范围是支付的前提，超出范围不报销
- 本技能提供政策依据与查询协议，不替代医保经办系统与医院医保办的专业判断
