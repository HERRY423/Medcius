# 中国医院处方审核（Prescription Review）

依据中国法规审核处方合理性。中国处方审核体系以《处方管理办法》（卫生部令第53号）和《医疗机构处方审核规范》（国卫办医发〔2018〕14号）为核心，由药师负责处方审核。

## 第一步：了解处方审核法规框架

**核心法规：**
1. **《处方管理办法》**（卫生部令第53号）— 处方开具、调剂、审核的基本规定
2. **《医疗机构处方审核规范》**（国卫办医发〔2018〕14号）— 处方审核的具体要求
3. **《医院处方点评管理规范（试行）》**（卫医管发〔2010〕28号）— 处方点评制度
4. **《抗菌药物临床应用管理办法》**（卫生部令第84号）— 抗菌药物分级管理
5. **《药品管理法》** — 药品使用的基本法律

**处方审核要点：**
- **合法性审核** — 处方开具资格、处方格式、处方有效期
- **规范性审核** — 患者信息、诊断、药品名称、剂量、用法、用量
- **适宜性审核** — 适应症、禁忌症、相互作用、配伍禁忌、重复用药、特殊人群

## 第二步：审核处方内容

**逐项审核：**

1. **处方基本信息**
   - 患者姓名、性别、年龄、病历号是否完整
   - 临床诊断是否明确
   - 处方日期是否在有效期内（一般处方当日有效，最长不超过3天）

2. **药品信息**
   - 药品名称（通用名）是否正确
   - 剂型、规格是否合理
   - 用法用量是否符合药品说明书
   - 给药途径是否正确

3. **用药适宜性**
   - 适应症是否与诊断相符
   - 是否存在禁忌症（如妊娠期、哺乳期、肝肾功能不全）
   - 是否存在药物相互作用
   - 是否存在配伍禁忌
   - 是否存在重复用药（同一成分不同商品名）
   - 剂量是否在安全范围内（特别是儿童、老年人、肝肾功能不全患者）

4. **特殊管理药品**
   - 抗菌药物是否符合分级管理（非限制使用/限制使用/特殊使用）
   - 麻醉药品、精神药品是否符合特殊管理要求
   - 处方用量是否符合规定（急诊3日量、门诊7日量、慢性病可延长）

## 第三步：输出审核意见

输出格式：

```
【处方审核意见】
处方编号：×××
审核结果：合理 / 不合理 / 需修改

【处方信息】
患者：×××（男，45岁）
诊断：2型糖尿病
药品：二甲双胍片 0.5g×60片
用法：口服，一次0.5g，一日2次

【审核发现】
1. 适应症：合理（二甲双胍为2型糖尿病一线用药）
2. 用法用量：合理（符合说明书推荐剂量）
3. 相互作用：未发现明显相互作用
4. 特殊人群：无特殊禁忌

【审核结论】
处方合理，建议调剂。
```

**不合理处方示例：**

```
【审核发现】
1. 适应症：不合理（诊断为上呼吸道感染，处方开具抗菌药物阿莫西林，无细菌感染证据）
2. 用法用量：需关注（儿童患者，剂量需按体重计算）
3. 重复用药：存在（处方同时开具"对乙酰氨基酚片"和"复方感冒灵颗粒"，后者含对乙酰氨基酚）

【审核结论】
处方不合理，建议退回修改。
```

## 注意事项

- **处方审核是药师的法定职责**：本技能辅助药师审核，不替代药师的专业判断
- **抗菌药物分级管理**：特殊使用级抗菌药物需经会诊同意
- **特殊人群**：儿童、老年人、妊娠期/哺乳期妇女、肝肾功能不全患者需特别关注
- **中药处方**：中药处方审核需考虑辨证论治、十八反十九畏
- **不替代官方答复**：本技能提供的审核意见仅供参考，最终以药师专业判断和医院规定为准
