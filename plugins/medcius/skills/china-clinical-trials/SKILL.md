# 中国药物临床试验查询（China Clinical Trials）

查询中国药物临床试验登记与信息公示平台（国家药品监督管理局药品审评中心CDE维护）上的临床试验信息。中国临床试验监管体系与美国ClinicalTrials.gov不同，必须在国家药监局药物临床试验登记与信息公示平台登记。

## 第一步：明确查询需求

**确定查询维度：**
1. **药品名称** — 中药/化学药/生物制品的临床试验
2. **适应症** — 按疾病查找相关临床试验
3. **申办者** — 按制药企业或研究机构查询
4. **临床试验机构** — 按医院查询其开展的临床试验
5. **试验状态** — 进行中/已完成/已暂停/已终止
6. **试验分期** — I期/II期/III期/IV期/上市后研究
7. **伦理批件** — 查询伦理委员会审批信息

**关键背景：**
- 中国所有药物临床试验必须在中国药物临床试验登记与信息公示平台（www.chinadrugtrials.org.cn）登记
- 2020年版《药品注册管理办法》实施后，临床试验默示许可制度（申请后60个工作日内未否定即视为同意）
- I期临床试验在批准后3年内未启动的，需重新申请

## 第二步：查询临床试验信息

使用中国临床试验 MCP 连接器查询：

- `search_trials` — 按关键词搜索临床试验（药品名称、适应症、申办者、试验机构）
- `get_trial_detail` — 获取临床试验详细信息（试验方案、入排标准、主要终点、样本量）
- `get_trial_sites` — 查询临床试验机构（医院）列表
- `get_trial_results` — 查询临床试验结果
- `validate_trial` — 验证临床试验登记号有效性

**查询要点：**
- 药品名称使用**通用名**，必要时补充商品名或研发代号（如"阿托伐他汀钙片"或"CV-0102"）
- 临床试验登记号格式：**CTR** + 年份 + 序列号（如"CTR20251234"）
- 查询时注意试验状态（进行中/已完成）和分期（I期~IV期）
- 中国临床试验与国际多中心试验（MRCT）分别登记，查询时注意区分

## 第三步：输出临床试验信息

输出格式：

```
【临床试验信息】
登记号：CTR20251234
试验名称：阿托伐他汀钙片治疗高胆固醇血症的多中心、随机、双盲、安慰剂对照III期临床试验
药品名称：阿托伐他汀钙片
适应症：高胆固醇血症
试验分期：III期
试验状态：进行中
申办者：某药企
主要研究者：×××（×市×医院）

【试验设计】
试验类型：随机、双盲、安慰剂对照
样本量：600例
主要终点：LDL-C较基线的变化
次要终点：TC、HDL-C、TG变化

【临床试验机构】
1. ××医院（××市）
2. ××大学附属医院（××市）

```

## 注意事项

- **登记平台**：中国药物临床试验登记与信息公示平台是官方平台，数据以该平台为准
- **伦理审批**：查询伦理批件号和批准日期
- **知情同意**：临床试验必须获得受试者知情同意
- **GCP要求**：临床试验必须符合《药物临床试验质量管理规范》（GCP）
- **不替代官方答复**：本技能提供的临床试验信息仅供参考，最终以国家药监局和登记平台数据为准
