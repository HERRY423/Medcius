# 国家医保编码（NHSA Coding）

将临床病历转化为国家医疗保障局（NHSA）认可的医保结算编码。中国医保编码体系与美国ICD-10-CM/CPT体系不同，必须使用国家医保局发布的《医保版ICD-10疾病诊断与手术操作分类代码》和《医保药品分类与代码》。

## 第一步：确定医保结算清单上的诊断

医保结算清单（医保基金结算清单）反映的是本次住院/门诊的诊疗过程，而非患者全部病史。依据《医疗保障基金结算清单填写规范》：

**按以下顺序编码：**
1. 主要诊断（本次住院/门诊治疗的核心疾病）—— 医保结算清单的主要诊断是"经医疗机构诊治确定的导致患者本次住院/门诊就医主要原因的疾病（或健康状况）"
2. 其他诊断（本次住院/门诊期间诊治的合并症、并发症）
3. 手术及操作（本次住院/门诊期间实施的手术和操作）

**不纳入医保结算清单：**
- 不确定诊断——"疑似"、"待查"、"排除"等未确诊的诊断不编码；编码主要症状
- 仅作为既往史提及、本次未治疗的疾病
- 与本次住院/门诊无关的慢性病（除非本次进行了诊治或调整了治疗方案）
- 医保版ICD-10中标注为"不可作为主要诊断"的编码（如部分Z码）

## 第二步：按医保版ICD-10编码规则编码

**医保版ICD-10与临床版ICD-10的区别：**
- 医保版ICD-10由国家医保局发布，用于医保结算，与临床版（卫健委发布）在部分编码上有差异
- 医保版ICD-10包含"医保扩展码"（如糖尿病并发症的细分编码）
- 编码必须精确到医保版ICD-10允许的最细分类

**编码规则：**
- **不推断**病历中未明确记载的严重程度、分期、侧别、发作类型
- **并发症/亚型必须由临床医生明确诊断**，不能仅凭检验值、影像学发现推断
- **"其他特指"（.8）不是"未特指"（.9）**——只有病历明确记载了无独立编码的特定亚型时才用.8
- **不输出裸类目**——J45、E11、N20等单独出现不是可结算编码
- **医保版编码与临床版编码冲突时，以医保版为准**

## 第三步：通过国家医保编码连接器查询

使用国家医保编码 MCP 连接器的工具查询每一个诊断和手术操作编码——**包括你确信自己知道的编码**。医保编码每年更新，凭记忆的编码可能已过期。

- 使用 `search_codes` 查询诊断编码（`code_type="diagnosis"`），查询词使用病历原文加上第二步的特异性判断
- 使用 `search_codes` 查询手术操作编码（`code_type="procedure"`），使用CCHI（全国医疗服务项目技术规范）编码体系
- 使用 `lookup_code` 或 `validate_code` 确认所选编码——结算清单上的每个编码必须有效且可结算
- 连接器返回完整编码，包括第7位字符和X占位符。照抄连接器返回的编码，不要重新格式化

**如果连接器工具不可用，停止。** 告诉用户需要安装或启用国家医保编码连接器，不要凭记忆输出编码——凭记忆产生的编码正是医保编码错误的主要来源。

## 第四步：最终检查

逐条检查草稿列表：
1. 病历是否显示该疾病本次住院/门诊被诊治、管理或处理？
2. 特异性是否与病历记载完全一致——未详细记载用未特指，详细记载用特指？
3. 该诊断是否只有一个编码，且为完整可结算长度，来自查询结果？

三条全部满足才保留该编码。如果两个编码描述同一诊断，删除一个再回答。

## 输出格式

以独立行结束编码，使主要诊断明确：

```
主要诊断：E11.900
其他诊断：I10.x00, Z79.400
手术操作：47.0100（腹腔镜下阑尾切除术）
```

编码与连接器返回的完全一致。任何为特定结算系统做的格式转换都在下游完成，不在此处进行。

## 中国医保编码体系参考

| 编码体系 | 用途 | 发布机构 |
|---|---|---|
| 医保版ICD-10 | 疾病诊断编码 | 国家医疗保障局 |
| CCHI（全国医疗服务项目技术规范） | 手术操作编码 | 国家卫生健康委 |
| 医保药品分类与代码 | 药品编码 | 国家医疗保障局 |
| 医保医用耗材分类与代码 | 医用耗材编码 | 国家医疗保障局 |
| 医疗服务项目编码 | 医疗服务项目 | 各省医保局 |
